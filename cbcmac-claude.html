Raw CBC-MAC

CBC-MAC turns a block cipher into a MAC by running CBC "encryption" with a fixed zero IV and keeping only the very last block. Step through it bit by bit below, then break it three different ways and see how ECBC-MAC and CMAC repair it.

Every demo on this page uses this key. Toy block cipher E(k,·): a 6-round Feistel network on 16-bit blocks (n = 16), so you can read every bit. It is a real permutation but far too small to be secure; real CBC-MAC uses AES with n = 128.

Construction

One key, a zero IV, and only the last block leaves the box

Split the message into ℓ blocks of n bits, m = m[0] ‖ m[1] ‖ … ‖ m[ℓ−1]. Each block is XORed into a running chain value, and the result is encrypted. The tag is the final chain value:

t = E(k, … E(k, E(k, E(k, m[0]) ⊕ m[1]) ⊕ m[2]) … ⊕ m[ℓ−1])

Chaining

    
Flip one message bit and watch it reach the tag

    
Click any bit of m′ to flip it. Chain values before the first changed block stay identical; from that block on, each t′[i] looks like a fresh random value, differing from t[i] in about half of the 16 bits. This is why the tag depends on every block.

  

  

    
    
    
  

  

  






  

    
Attack 1 · Random IV

    
Why the IV must be fixed to zero

    
Suppose we copied CBC encryption and used a random IV, sending the tag as (IV, t). The first cipher input is IV ⊕ m[0]. An attacker who flips the same bits Δ in both the IV and m[0] leaves that input unchanged, so the old t stays valid for a different message. Attack 2 · Variable length

    
The one-query extension forgery

    
Raw CBC-MAC is a secure PRF when every message has the same number of blocks ℓ. Allow messages of different lengths and it breaks with a single chosen-message query. Raw CBC-MAC works on whole blocks, so here m is exactly one 16-bit block (2 characters).

At block 1 the chain value t meets m ⊕ t: t ⊕ (m ⊕ t) = m. The cipher sees m a second time and outputs t again.

    

  






  

    
Attack 3 · General case

    
Splice any two tagged messages

    
Given two valid pairs (m, t) and (m′, t′), the message m ‖ (m′[0] ⊕ t) ‖ m′[1] ‖ … ‖ m′[ℓ′−1] has tag t′. At the junction the chain value t cancels, and from there the computation is exactly the one for m′. The forgery even ends with m′'s padded last block, so 10* padding does not help.

Repairs

    
Making it safe for variable-length messages

    
The attacks above all work because the tag of m is also the chain value in the middle of every longer message that starts with m. Each fix breaks that link.

  

  

    
ECBC-MAC: encrypt the raw tag once more with an independent key k₁

    

    
The attacker now only sees E(k₁, t), never the chain value t itself, so the cancellation trick has nothing to cancel. Boneh's bound: for q tagged messages, AdvPRF[A, FECBC] ≤ AdvPRP[B, E] + 2q²/|X|, with |X| = 2ⁿ. With AES this means rekeying after about 2⁴⁸ messages. (The diagram uses k₁ = k ⊕ 9E3779B9 for display only; a real k₁ is generated independently.)

  

  

    

      
Prepend the length

      
Put the number of blocks ℓ into the first block, then run raw CBC-MAC. No valid message is now a prefix of another one. Secure, but the length must be known before processing starts. Appending the length at the end is not enough.

    

    

      
CMAC (NIST SP 800-38B)

      
The standardized variant. Derives two subkeys from k and XORs one of them into the last block before its encryption. One key, no extra cipher call, no dummy padding block. Use this in practice.

    

    

      
Rules that still apply

      
    
        
  • Never reuse the same k for CBC encryption and CBC-MAC.
    • 
        
  • Never release intermediate chain values: t[i] is the tag of the prefix m[0..i].
    • 
        
  • Compare tags in constant time.

Exam summary

    
What to remember

  

  

    

      
Definition
t ← 0ⁿ; for i = 0..ℓ−1: t ← E(k, t ⊕ m[i]); output t. Verify by recomputing and comparing.

      
Secure when
All messages have the same fixed length ℓ: raw CBC-MAC is then a secure PRF on X^ℓ, hence a secure MAC (up to the birthday bound q ≪ 2^(n/2)).

      
Broken when
Lengths vary. One query on m gives t; then m ‖ (m ⊕ t) has tag t. In general m ‖ (m′[0] ⊕ t) ‖ m′[1..] has tag t′.

      
IV
Must be fixed (0ⁿ). A random IV sent with the tag lets the attacker change m[0] freely: (IV ⊕ Δ, m[0] ⊕ Δ ‖ …) keeps the tag.

      
Fixes
ECBC-MAC E(k₁, rawCBC(k, m)), length prepending, or CMAC (the standard).
